# Machine Learning Model Evaluation App

## Project Overview
This project compares five machine learning classification algorithms using the Breast Cancer Wisconsin Diagnostic dataset.

## Dataset
- 569 rows
- 30 input features
- Target: Malignant or Benign

## Models
- Logistic Regression
- Decision Tree
- KNN
- Naive Bayes
- SVM

## Evaluation Metrics
Accuracy, AUC, Precision, Recall, F1 Score, MCC.

## How to Run
Install dependencies:

    pip install -r requirements.txt

Run the app:

    streamlit run app.py
